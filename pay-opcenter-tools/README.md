# pay-opcenter-tools

支付运营平台工具集，专门用来作为大模型（Agent）操作支付业务后台的能力抽象层。涵盖了路由规则、通讯模板、提现渠道、商户信息等 500+ 个功能页面的自动映射与能力下沉。

## Installation

建议以仓库模式直接访问或者将此目录软链接入对应 AI Agent 的 skill 安装点。

```bash
# 全局映射 (以 Claude Code 为例)
ln -sf $(pwd)/skills/pay-opcenter-tools ~/.claude/skills/pay-opcenter-tools
```

首先需要完成登录授权鉴权：
```bash
cd skills/pay-opcenter-tools
python3 shared/base_client.py config --token <OAuth_TOKEN>
```
*Token 获取方式：打开 https://pay-opcenter.prod.fin.qima-inc.com/ → F12 → 应用 → Cookie → OAuth_TOKEN*

## Usage Details

在 AI 对话窗输入类似下列自然语言：

- "帮我查询一下微信支付的路由规则，灰度码是 test001"
- "列出当前可用的商户信息配置，终端序列号为 99887766 的"
- "最近的提现渠道状态怎么样，只看前 10 条"

系统（AI Agent）会自动查阅 `router_manifest.json` 加载对应业务域与功能执行器，将自然语言意图转化为具体的 HTTP 请求参数（补全接口要求的必传默认校验等），最终生成数据表格或者通过大模型对返回原始 Json 进行诊断分析输出。

## Features Overview
- **零幻觉参数提取**：通过前期流水线精确扫码前端代码中对后端的 Axios 调用。入参中的必填字段与默认参数（比如状态等）都会从原页面还原给大模型。
- **降维的分发模型**：通过 `router_manifest.json` 在全局只暴露少数业务大域（如“渠道域”等），减少一次性载入的 Context Length 数十倍，有效解决 Token 溢出难题。
- **状态续传与演进**：通过 `progress.json` 进行转化工作流水追踪，支持随时加入更多的业务范畴。
