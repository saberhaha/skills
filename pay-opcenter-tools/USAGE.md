# pay-opcenter-tools 使用指南

用自然语言查询支付运营平台数据，无需打开后台

---

## 快速开始

### 第一步：配置登录凭证（首次使用）

```bash
cd .claude/skills/pay-opcenter-tools
python3 shared/base_client.py config --token <你的_OAuth_TOKEN>
```

**获取 Token：** 浏览器打开 `https://pay-opcenter.prod.fin.qima-inc.com` → F12 → 应用(Application) → Cookie → 复制 `OAuth_TOKEN` 的值。

Token 保存在本地 `~/.config/zan-tools/pay-opcenter-token.json`，配置一次长期有效（Token 过期后重新执行上面的命令即可）。

---

### 第二步：直接用自然语言提问

在 Claude Code 对话框中，按以下格式描述需求：

```
查询 [业务对象] 的 [查询条件]
```

**示例：**

```
查询灰度码为 test001 的路由规则
查询微信支付的通讯模板，只看可用状态的
查询店铺 12345678 的商户信息
查询近 7 天的退款异常记录
查询 wsc 业务线下状态为已发布的页面证书
查询 PayTools 全局配置当前已发布的规则
查询收银台插件正式版的最新版本
查询外部账户 1234567890 近 30 天的明细
```

## 常见问题

**Q：Token 过期了怎么办？**
重新执行配置命令，粘贴新 Token 即可覆盖。

**Q：查询结果如何展示？**
表格类功能以 Markdown 表格输出；详情类功能以结构化字段输出。AI 会根据功能类型自动选择。

**Q：能执行修改/删除操作吗？**
不能。本工具集仅覆盖查询类功能，所有操作均为只读，不会对生产数据产生任何变更。

**Q：找不到想查询的功能怎么办？**
直接描述业务意图，AI 会尝试匹配最接近的功能。如确实未覆盖，会明确告知。
