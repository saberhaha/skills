# Excel 按日拆分工具 (excel-monthly-splitter)

当用户提供一个**Excel文件**（通常是一个月的数据），并且要求你按日期把这个文件拆分时，你应该使用此 Skill。

## 场景描述

- **输入**：一个多 Sheet 的 Excel 文件，每个 Sheet 的第一列均为日期（Date）。表格实际数据从第二行开始，第一行为无关信息。
- **要求**：
  1. 读取 Excel 文件中的每个 Sheet 时，从第二行开始提取列头（表头）。
  2. 第一列强制命名为“交易日期”。
  3. 如果某些单元格无数据，自动使用 `0` 补充。
  4. 根据每个 Sheet 的第一列（交易日期）进行分组拆分，遇到非日期数据或空字段将直接丢弃整行内容，同时严格将格式重置为 `YYYYMMDD`（如 `20251106`）。
  5. 将拆分后的数据以带有表头的 `txt` 格式输出（以 `|` 作为分隔符，并带有指定的首行信息：`1.0.0|991100001624|911100000005|1|{YYYYMMDD}|{YYYYMMDD}`）。
  6. 根据生成的有效日期命名归类文件夹，并在生成文件名称时自动剔除 Sheet 名称中的“网联”两字（例如若 Sheet 为 `网联A01`，则名字将被清洗为 `A01`，最终命名为 `20251106/991100001624_XTON_20251106_A01_04.txt`）。

## 执行指南

本 Skill 提供了一个内置的 Python 脚本来完成上述复杂的数据处理工作，从而避免因为表格太大导致代理本身的内存或回复长度溢出。

**执行步骤**：

1. **确认输入与输出**：
   - 首先向用户确认需要处理的 Excel 文件的绝对路径（或在当前上下文中找到对应的文件）。
   - 确认希望存放拆分结果的输出目录路径（若用户未指定，默认可在 Excel 同级目录下创建一个带 `_split_output` 后缀的文件夹）。
   - **确认批次号**：询问用户是否需要指定批次号（txt文件名的最后两位，例如 04）。如果用户没有指定，从新询问用户，直到用户明确指定或明确表示不指定（告知将默认使用 04）。

2. **检查环境依赖**：
   - 确保执行环境中已经安装了 `pandas` 和 `openpyxl`。你可以使用后台终端提前进行检查并安装：
     ```bash
     pip install pandas openpyxl
     ```

3. **运行拆分脚本**：
   - 找到本 Skill 目录下的核心脚本文件：`scripts/split_excel.py`
   - 使用终端工具执行该 Python 脚本：
     ```bash
     python /绝对路径到本Skill目录/scripts/split_excel.py <Excel文件路径> <输出目录路径> [批次号]
     ```
     *注意：批次号是可选的，如果不提供则脚本默认为 04。*

4. **汇报与验证**：
   - 脚本执行完毕后，使用 `list_dir` 检查输出目录，确认是否生成了按日期命名的文件夹，以及每个文件夹内对应的 `*.txt` 数据文件。
   - 向用户汇报处理结果，比如列出了哪些日期的文件夹，并截取其中一个文本文件（使用 `view_file` 或 `cat`）展示表头和拆分格式正确无误。

## 代码说明

内部自带脚本 `split_excel.py` 的核心逻辑如下：
- 使用 `pd.read_excel(..., header=1)` 遍历所有 Sheet 从第二行提取表头。
- 强制覆盖第一列属性名为 `交易日期`，对该列使用 `pd.to_datetime(..., errors='coerce')` 验证并清洗所有非日期非法数据（这些非法行将被 `dropna` 清除掉）。
- 剔除了非法日期行后，利用 `dt.strftime('%Y%m%d')` 强行格式化所有第一列内容输出如 `20251106` 的格式。
- 使用 `df.fillna(0)` 填充无数据的字段。
- 使用 `df.groupby` 利用已格式化完成的日期进行遍历分组，并借此建立文件夹。
- 文件命名处利用 `replace('网联', '')` 方法剔除原表名中的“网联”修饰词，保证输出文件的准确命名。
- 利用 `.to_csv(..., sep='|', index=False)` 加上首行拼接，导出带有定制头和原始表头的 `txt` 文件。
