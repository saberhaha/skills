# 输出格式说明

## 控制台输出

```
作者                                commit总数   采样   AI占比
────────────────────────────────────────────────────────────
zhang.san@company.com                      87     50   73.2%  ███████░░░
li.si@company.com                          43     43   41.5%  ████░░░░░░
wang.wu@company.com                        61     50   28.9%  ██░░░░░░░░
────────────────────────────────────────────────────────────
团队整体                                  191          52.1%
```

- **commit总数**：该时间段内实际 commit 数
- **采样**：实际打分的 commit 数（超过50个时随机采样）
- **AI占比**：采样 commit 的平均 AI 概率分，按行数加权
- **进度条**：每格=10%

## CSV 输出

`ai_ratio_report.csv`：

```csv
author,total_commits,sampled,ai_probability
zhang.san@company.com,87,50,73.2
li.si@company.com,43,43,41.5
```

## 解读建议

- **>70%**：高 AI 使用，代码大量借助 AI 生成
- **40-70%**：中等，AI 辅助编写
- **<40%**：以人工为主
- **注意**：分数是概率估算，不是事实。跨月对比趋势比单月绝对值更有价值。
